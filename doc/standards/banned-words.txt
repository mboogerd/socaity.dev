# socaity.dev — banned wordlist for public surfaces
#
# Canonical machine-readable half of doc/standards/vocabulary-and-visual.md.
# Consumed by the CI banned-wordlist gate (socaity-ddi), per 1ux clause 10.
#
# FORMAT
#   One pattern per line. Blank lines and lines starting with "#" are ignored.
#   Patterns are POSIX extended regular expressions, matched CASE-INSENSITIVELY.
#   A pattern that begins with "~" is REVIEW-REQUIRED, not banned: the gate
#   reports it and the build passes only if the matching line carries an inline
#   waiver comment  <!-- vocab-ok: <reason> -->  (HTML/Markdown) or
#   # vocab-ok: <reason>  (code/config). Strip the leading "~" before matching.
#   Every other pattern is FAIL-level: any match fails the build, no waiver.
#
# SCOPE
#   All owned public surfaces: site pages, manifesto, FAQ, README, blog posts,
#   OG card text, RSS, social mirror-out copy, grant application public text,
#   and alt text. NOT applied to: doc/ internals, council/*.md, .claude/skills/,
#   or code comments — internal precision is allowed to use words public copy
#   must not. Keep that boundary explicit in the gate's path filter.
#
# EDITING RULE
#   Patterns are narrow on purpose: a false positive teaches authors to disable
#   the gate. Never widen a pattern to a bare common English word. Add the
#   phrase, not the word.
